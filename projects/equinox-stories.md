# Equinox Stories — Mobile Narrative Application

## Context
A private Android narrative-game project included as an example of build/release discipline outside my primary infrastructure specialization.

## Documented test-build scope
- two interactive stories
- offline/local progress
- multilingual UI
- character/outfit systems
- audio and visual assets
- Android API 36 test build

## Validation
The documented test release includes APK signing checks, ZIP alignment verification, byte-level asset checks, hundreds of engine transition checks, thousands of story-path executions and layout/language scenarios.

## Why it is in this portfolio
The project demonstrates structured release validation, automation and the ability to deliver across a broader software stack. Source and creative assets remain private.
